# Fuentes de fotografías

Las fotografías están descargadas localmente en `assets/images/recipes/` para que la app no dependa de enlaces externos. Se usan como imagen representativa del platillo; **no modifican ni inventan datos de las recetas verificadas**. Tampoco fueron verificadas por Gemini: un intento de validación visual con el modelo devolvió errores de servicio, por lo que se documenta su procedencia y licencia de Wikimedia Commons en su lugar.
